# macos/Tokenory/Views/
> L2 | Parent: ../../../AGENTS.md

BrandIcon.swift: 统一工具、提供方、模型的品牌映射。TRAE CLI 与 Trae 共用品牌标志。
CursorTooltip.swift: 即时更新图表悬停目标。指标、图表和工具标签的浮层在同一目标停留 150 ms 后显示，活动日历等 240 ms。离开目标关闭浮层。独立前景层按指针和图形避让，允许鼠标穿透。
DashboardView.swift: 组织统计窗口导航与重试。侧栏更新状态右边的齿轮打开设置窗口。首次慢加载显示总览占位，切换范围时保留上一份完整报告。明细页与「只看本机」要求完整本机报告，查询失败可重试。主动扫描立即在刷新按钮显示进度。宽窗口同时显示记录列表与所选详情，窄窗口保留原生面板。
DashboardMotion.swift: 使用共享计数值、进位和借位静音滚动统计数字；大跨度快进后滚完最后一段，单位变化时淡入新读数；记录图表从无数据恢复时的日期切换；遵循减少动态效果设置。
DashboardChartMarks.swift: 由 Core Animation 绘制按本机和其他设备堆叠的柱形与分段费用曲线。模型历史通过焦点遮罩淡化非焦点区域。
DisplayNumberFont.swift: 从 App 资源加载 Maple Mono NF CN SemiBold，用于统计窗口和菜单栏的大号读数及其滚动动画。
DeviceSyncSettings.swift: iCloud 同步和存储操作分卡，说明居左、操作居右，包含小号开关、相对同步时间、手动刷新、「删除数据」打开范围菜单再确认及上次删除结果核实，两步均默认高亮取消，独立账本显示同步条件。
ImportView.swift: 数据页从「选择文件」直接选取历史文件并自动识别格式，展示导入预览、来源冲突和可撤销的已导入记录。设置内的来源页按设备排列，设备用量采用同一颜色，支持的客户端与导出各用一张卡片，导出范围居左，右侧菜单选择 JSON 或 CSV，本机工具内可查看采集诊断、来源覆盖和计入量，首次读取失败可重试。
MenuBarView.swift: HUD 显隐使用文案后的勾选菜单项；展示今日 Tokens、费用、加权速度及来源用量。首次读取失败支持重试，同日已有用量时保留读数。主动扫描立即显示进度。采集状态独立于今日用量的读取结果。
OverviewView.swift: 按所选范围展示多设备合计与下方本机数值，在指标数字上悬浮查看各设备，本机和 Fast 用对齐的图标、标签与数值，滚动更新 Token 构成与排行读数。独立子代理卡汇总 Codex 与 Antigravity 的启动数、Tokens、估算费用及占比，展开后显示与本机快照修订一致的本机对话。工具排行按 App 与 CLI 分别取 Antigravity 子代理统计。Token 构成与用量趋势共用顶部卡片，洞察位于使用习惯正上方。点击整个工具行可展开或收起该工具使用的模型。日期范围为空时只展示一处空态，全年有记录时继续展示活动数据。工具与模型排行共用 Tokens/费用切换和 Fast 图例，横条按所选指标区分 Fast 占比。对未计入的设备显示兼容性提示。
PriceCatalogView.swift: 展示默认收起、按供应商独立折叠的完整价格目录；下拉内搜索供应商或模型、切换全部和账本已用范围、选择单个模型，标明 compactor 参考估算，在 DeepSeek 表内展示峰谷价格和时段说明。
RecordsView.swift: 展示用量明细及当前筛选下的 Tokens 和估算费用合计。窄布局显示简体中文短日期，同页重复日期只格式化一次。列表缩短时自动回到最后有效页，单页隐藏分页。无记录时提供清除筛选或更改日期。
SettingsView.swift: 通用页用对齐的下拉选择外观和语言，并管理币种和登录项，关于页展示版本与更新控制，数据页合并导入与备份恢复。其余分区为 HUD、价格、采集、来源和 iCloud 同步。采集设置显示系统时区，保存按钮在扫描路径卡片内显示进度、成功及重试；采集提供 30、60、120 秒间隔并保留已有自定义值，显示只读的扫描器默认位置，并对新增自定义路径校验重复。通用和更新频率选择器按本地化文案计算宽度。价格页左侧说明，右侧用一个按钮刷新费率并在卡片内预览重算。已有估算经确认后写入。右侧「备份管理」菜单提供创建和恢复入口。恢复前确认文件与影响，操作旁显示进度、结果和重试。
MechanicalHUDView.swift: 原生橙色机械计数器按原型 50% 显示（220×92 pt 窗口）；双击读数或外壳在系统连击间隔后打开统计窗口，三击取消待打开动作并按设置关闭、暂时隐藏或忽略；文本片段/费用图标、渐停数字轮，滚动音效仅在面板所在空间可见时播放，开启音效时试听；复用 UsageStore 持续更新的当日汇总；每帧捕获数字位置快照，避免延迟绘制访问已清空或缩短的数组。
HUDSettingsView.swift: 六个位置按钮使用工作区选中色标明当前 HUD 位置。设置页控制 HUD 显隐、闲置自动隐藏、三击动作、音效和音量。音效开启时出现右侧音量控件，每 5% 一档，调节即试听。显示指标和音效可直接在 HUD 切换。
UsageDatePicker.swift: 通过工具栏和明细空状态打开共用日期浮层；弹出时初始化草稿和两个月的日历。点一次可应用单日，点第二天可应用日期范围。
UsageFiltersView.swift: 单行选择工具、提供方和模型，浅色模式的三个收起按钮使用灰色标签与箭头。工具和提供方按所选设备范围内的账本合计 Tokens 排序，模型按名称排序。明细额外按来源及最近活动优先的对话筛选。
UsageTrendChart.swift: 按本机或设备汇总时区绘制双轴日/小时多设备堆叠趋势，费用线和设备色块使用等宽图例。日期切换时插值 Tokens 柱高，沿时间轴描出费用。趋势和模型历史统一支持悬停预览、点击固定和再次点击或 Esc 清除。
UsageActivityView.swift: 使用固定 YlGnBu 色阶并将全年格子适配卡片宽度。悬停立即放大提亮，并挤压八个邻格。读数浮层在同一格停留 240 ms 后显示。鼠标点击与悬停共用日期命中，含放大边缘。键盘和辅助功能通过每格按钮开合当天详情，独立按钮进入当日总览。
UsageHabitsView.swift: 随总览设备范围展示最高产星期、单日最高、星期和 24 小时分布。星期和小时柱形即时高亮，浮层延迟出现。宽窗口并排，窄窗口堆叠。
UsageHistoryChart.swift: 跟随总览的设备范围，展示按工具分组的模型堆叠走势和原始总量。使用图内整刻度和半刻度，悬停或固定读数时强调当前日期，淡化走势的其余部分。单击切换 30 天平均和每日数据。
UsageViews.swift: 「只看本机」工具栏标签在深浅色下随窗口失焦变灰。提供用量格式、跨设备悬浮明细、按本机普通／Fast 和其他设备普通／Fast 全高并排的份额条、跨页 Fast 闪电标记和菜单栏三项摘要。悬浮明细先显示合计与本机，再按与来源页相同的设备名称和 ID 顺序列出其他 Mac。
WorkspaceControls.swift: 提供总览卡片共用的 SF Symbol 标题、前缘对齐和统一展开间距。错误采用设置行布局，左侧显示警告图标、标题和可选中详情，右侧显示原生操作。独立错误用警告面板，已有卡片和菜单栏内沿用行内布局。下拉共用触发按钮、搜索框、选项行和带勾选的弹窗。深色下拉按钮使用提亮的底色和灰色文字。主窗口和设置的下拉文字失焦时使用系统灰，设置中的强调操作按钮和菜单也随失焦变灰。说明按钮点击展开原生浮层，设置开关统一使用小号原生样式。
WorkspaceStyle.swift: 定义随系统切换的 Tokyo Neon 和 Tokyo Neon Light、普通卡片底色和琥珀色警告底色。卡片只绘制表面，文字在标签上设色，控件随窗口焦点使用系统底色。蓝色和薄荷绿区分设备，粉色标记费用，黄色标记 Fast。浅色模式的选中态使用图标指针的品牌蓝，深色模式使用霓虹粉。

TurnsView.swift: 多 agent 回合摘要、工具与模型筛选、能力弹窗、时间分组筛选及回合详情。默认按回合开始时间倒序，可按项目、已保存回合名和 ID 搜索。每页 6 条，末页保持列表高度。宽窗口详情与列表等高，窄窗口上下排列。详情用间距分组，精简数据口径通过帮助控件查看。无回合时显示一处页级空态，请求失败提供重试。
TurnSpeedChart.swift: 按系统时区绘制小时、日或周速度箱体及稀疏与离群回合；离群点对齐所属箱体中心，悬停或用键盘可查看原始回合时间，点选保留搜索，再点或 Esc 收起。
