DeviceCloudSyncTests.swift: 验证独立设备授权、暂停与撤回、请求乱序、账本恢复、增量缓存、离线与账号切换，以及断网时本机合计更新、联网补传和删除错误保留。日期切换保留完整的前一份双机汇总，过期计算无效，纯日期改动复用全年活动。 覆盖停传等待、核实删除与新删除、写失败时继续读取、撤销提示、刷新抢占、版本隔离及仅下载远端资产。
HUDTests.swift: 验证闲置隐藏默认关闭、开关与唤醒、价格更新不唤醒、原生面板双击打开统计、三击取消打开并关闭或忽略及偏好持久化；验证跨时区与 23/25 小时夏令日；验证整数与金额读数、未知/部分价格、进位和渐停、跨日/切换/减少动态效果、滚动中连续追加与密集更新、设置持久化、字体/双语资源及浮动面板的全屏空间配置。
LocalizationTests.swift: 验证本地化资源、本地午夜及后台发出的跨日、时区变更和唤醒通知在主线程触发刷新。
UsageActivityTests.swift: 验证日历、按工具区分模型、移动平均、未知费用及走势右轴的整刻度、半刻度和分档。
PresentationDataTests.swift: 验证深浅主题的 sRGB 色值、卡片内下拉与原生控件在失焦时的底色、统计展示数据、筛选项按所选设备范围内的 Tokens 排序、悬浮明细的设备顺序、跨设备排行四段的占比、顺序和全高 Fast 像素、唯一模型数、缺失费用、日期图表入场、夏令时重复小时、统计数字进借位与单位变化，以及大号读数从 App 包内加载的字体和中文单位字形。
UpdateCheckerTests.swift: 验证更新检查状态及应用语言对应的清单。
UsageStoreTests.swift: 真实 Codex 文件追加经 worker 更新当日用量并连续追加当前滚动；验证今日速度独立筛选、跨日旧响应不覆盖、完整来源能力目录；验证日期切换保留上一份报告且复用全年活动、按天数移动日期范围、今日上限及恢复滚动预设。

UsageStore 的统计回归覆盖首次请求失败、筛选失败保留旧报告、汇总预览后重试明细和恢复时清除旧日期缓存。来源刷新失败时保留缓存，错误在来源页展示；worker 重启后重试会清除该错误。
扫描恢复回归覆盖确认状态后清除旧超时、重试无变更账本上的统计请求、保留无关错误、后台故障保持安静和保留同日读数。
对话筛选回归覆盖明细隔离、分页重置和清除筛选时保留日期。

TurnAnalyticsTests.swift: 验证速度加权、按项目、会话标题及回合 ID 搜索、估算标记、可选 Fast 证据、协议校验、小时／日／周分组、周边界、四分位、离群点与箱体对齐及稀疏点的实际时间。

CursorTooltipTests.swift: 校验悬停目标即时更新、浮层延时和取消，以及读数位置、翻侧避让与固定尺寸。在带工具栏的原生分栏窗口采样浮层像素，核验可见性与鼠标穿透。

SourcesPresentationTests.swift: 检查本机按工具归组后能保留多来源覆盖、空采集和部分错误。
