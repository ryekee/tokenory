# Mechanical HUD demo

Approved interactive prototype for Tokenory, retained for the future website.

Open `index.html` directly, or serve this directory with any static HTTP server. No build step, network font request or package dependency is required. Saira Extra Condensed SemiBold is embedded in the HTML; its SIL Open Font License is included here.

The demo uses simulated daily totals. It includes metric switching, mechanical acceleration/deceleration, Web Audio clicks, mute, volume, and desktop backgrounds. It does not read the local ledger. Native implementation lives under `macos/Tokenory/`.
