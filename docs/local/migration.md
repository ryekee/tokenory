CLI 示例：`tokenory --data-dir <目录> import preview --source tokens-ci <文件>`；检查后使用 `import apply <id> --accept-original-dates --accept-partial-dates`。与已有本地日志重叠时，必须选择已有或导入来源，不能相加。

源导出没有提供方时保留 `unknown`，不根据工具名称伪造模型供应商。源成本与 API 估算独立保存。原始个人文件不进入 Git。
