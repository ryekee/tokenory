# 估算口径

Tokenory 保存源成本和独立的 API 参考估算。缺价格时估算为 null；源数据的 0 不表示免费。每条估算保存不可变价格快照 ID 和假设，刷新价格不改变已存估算，重估须先预览。

DeepSeek 参考价核验于 2026-11-05，来自 [官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)。首版明确采用固定峰时 API 等价估算，忽略非峰时及节假日优惠；这不是账单还原。Flash 的输入/缓存命中/输出分别为 $0.3/$0.006/$1.2 每百万；V4 Pro 为 $1.32/$0.044/$3.96。没有发起付费请求。

其他模型沿用上游有可靠模型和提供方证据的价格及缓存 TTL、长上下文计算。日汇总只用基础费率，不作为一条长请求；历史费率未知时保留当前参考价假设。观察到 Fast/Ultrafast 而未取得对应费率时保持未计价，用户可以明确设置该档位价格。

价格数据源缓存与 Tokenory 数据目录隔离，离线时已存快照和估算可用。来源时间是抓取/缓存快照时间，不冒充费率生效时间。

事件计价复用上游 lookup-aware 入口，保留 matched key / source / provider 对整请求档位的影响。回归样本：直接 OpenAI 的 300,000 输入、10,000 输出按上下文档位估算 $6.75；相同日汇总按基础费率估算 $3.50，二者不混用。
