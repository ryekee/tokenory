# Tokenory 0.1.6

### 看看一个回合花了多少时间

新增「速度」页面，查看已完成回合的平均速度、首 token 等待时间和推理 token 数量。按日期、工具和模型筛选，查看速度趋势，也可以按耗时、时间、速度或推理量排列回合。打开回合详情，可以查看生成的 tokens，以及有记录时的工具等待时间。

速度等于生成 tokens 除以完整回合耗时，包含工具等待时间。它反映回合吞吐量，并非模型的纯解码速度。缺失的数据显示为 `—`，估算值标记为 `≈`。

### 在菜单栏查看今日摘要

菜单栏新增今日速度，与 Tokens 和费用一起显示。这里的摘要独立于统计窗口的筛选条件。

### 查看哪些工具有速度数据

目前 12 个客户端至少有一种格式可提供速度数据，包括 Codex、Claude Code 和 OpenCode。Paseo 和 Orca 使用底层客户端日志，因此筛选结果包含对应客户端的全部可用回合。其余 28 个入口暂不支持速度统计。打开支持列表可以查看图标，悬停显示名称。各格式的支持范围和限制见[覆盖详情](https://github.com/ryekee/tokenory/blob/main/docs/local/agent-speed-coverage.md)。
