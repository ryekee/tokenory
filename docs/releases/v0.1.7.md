# Tokenory 0.1.7

### 新增

- 新增橙色机械悬浮 HUD，可切换查看今日精确 Token 数量和估算美元费用。
- 支持六个屏幕边缘位置，HUD 会跟随鼠标所在的显示器。
- 滚轮音效默认关闭，可在设置中调整音量。
- Codex 已确认的日志用量会实时刷新；跨日及唤醒时按设备时区更新。

### 改进与修复

- 新增 GPT-6.2 Astra 和 Sol 的官方 API 参考费率，支持长上下文、Fast 和 Ultrafast。
- 修复 HUD 读数为空或位数缩短时可能发生的崩溃。
- 限制自动备份和预览文件的保留量，减少磁盘占用。
- 更新下载改用公开的 GitHub Release 地址，避免受到匿名 API 额度限制。
