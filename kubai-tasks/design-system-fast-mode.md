# 在统计窗口识别 Fast 模式

总览在 Tokens 汇总区显示有记录依据的 Fast tokens。明细和速度的列表在对应记录边上显示闪电，详情和速度单点提示显示闪电和 Fast 字样。三页共用一个语义标记、系统图标和次级文字样式。

Codex 系记录以日志里的显式模式为依据，Claude 以回复报告的模式为依据。悬停提供模式来源。聚合展示所选范围内的已标记用量；缺少模式证据的旧数据继续保留。
